# Hachimi 客户端安全审计

对某 Minecraft 客户端模组的一次安全审计与隐私补丁。
即 `hachimi-b4-crk.jar`
由gpt6.1 sol ultra破解编译

## 结论

- 模组自带一个 Windows 原生库，经过加壳保护。
- 该原生库存在收集本机 QQ 账号信息的行为（扫描 QQ 数据目录、调用本机 QQ 登录接口）。
- 已通过补丁去除这些 QQ 信息检测读取，改为返回空结果，并阻断后续联网上报。

## 使用

将 `hachimi-b4-crk.jar` 放入 Minecraft Fabric 实例的 mods 目录即可。java启动项添加-Xverify:none
否则可能崩溃

## 风险与免责

- 所有原上报逻辑已删除，不会读取并发送 QQ 数据。
- 不构成"绝对安全"的保证：加壳代码中可能仍有未识别的行为。
- 本仓库仅供安全研究与学习，请勿用于商业用途。
